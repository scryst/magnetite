# Media

The stills in the README are frames from `site/media/film.mp4`, a screen
recording of the app, cropped and resized with FFmpeg and `cwebp -q 86`.

Music and cover art: Punch Deck, "Chrome Funk", "Cyberpunk Renaissance" and
"Neon Underworld", [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
